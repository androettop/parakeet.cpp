parakeet.cpp · live mic multi-thread

Real-time transcription with a multi-core ggml pool running in a Web Worker: the mic capture and UI stay smooth on the main thread while the model decodes in parallel off-thread. Uses the cache-aware streaming model with end-of-utterance detection.

Must be a streaming model: realtime_eou_120m-v1 (English) or a nemotron-3.5-asr-streaming model.
